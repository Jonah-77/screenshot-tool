# 截图工具（Windows 框选连续截图）

一个给 Windows 用的小工具：**框选屏幕区域，一键截图并自动向下滚动**，专门用来把长聊天记录、长文档连续截成一串图片。

原本是为了把一个很长的微信聊天记录截成图片、再交给 AI 分析而写的。

## 它解决什么问题

普通截图工具截长内容，要么手动滚一下截一张（几十次），要么用滚动截屏（很多应用不支持，或者截出来是拼接的糊图）。

这个工具的做法是：

1. 框选一块固定区域
2. 点一次「截图并下滚」→ 截一张 + 自动把内容往下滚一屏
3. 再点一次 → 再截一张 + 再滚一屏

每张都是**独立清晰的整屏截图**，不是拼接的。想省事就按「自动连拍」，它自己一张张截下去，滚到底会自动停。

## 功能

- **框选区域**：全屏半透明遮罩上拖出矩形，松开即选定
- **红框标记**：选中的范围用红框常驻标出，随时知道在截哪儿（红框不接收鼠标，不影响你点下面的窗口）
- **截图并下滚**：截一张，然后模拟滚轮向下滚 N 档
- **自动连拍**：连续截 + 滚，画面不再变化时自动停（说明到底了），也可以按 **End** 键或点「停止连拍」随时停
- **单张**：只截一张不滚动，用来补拍
- **不抢焦点**：面板不会夺走当前窗口的焦点，滚轮直接作用在你正在看的窗口上
- **鼠标归位**：滚动完成后鼠标自动回到按钮位置，可以连续点
- **自动编号**：图片按 `001.png`、`002.png` 递增，存在桌面「截图」文件夹

## 环境要求

- Windows 10 / 11
- Python 3.9+，需要 `Pillow`

```bash
pip install pillow
```

> 只用到标准库的 `tkinter`、`ctypes` 加一个 `Pillow`，没有其他依赖。

## 运行

```bash
python 截图工具.py
```

不想看到黑色控制台窗口的话，用 `pythonw` 启动：

```bash
pythonw 截图工具.py
```

**推荐做法**：在桌面建一个快捷方式，目标填 `pythonw.exe`，参数填这个脚本的完整路径。以后双击就行，不会有黑框。

## 用法

1. 打开你要截的内容（聊天记录、文档、网页），**先滚到最顶部**
2. 双击启动工具，屏幕变暗，拖出一个矩形框住内容区
3. 反复点「截图并下滚」，或者点一次「自动连拍」让它自己跑
4. 图片存在 `桌面\截图\`

### 「下滚档数」怎么调

面板上的 `−` `＋` 调的就是每次滚多少，默认 3 档。

- 数字太小 → 相邻两张重叠很多，张数变多
- 数字太大 → 可能中间漏掉内容

**建议**：宁可重叠，不要漏。先试一次，看看相邻两张能不能接上，再微调。

## 已知限制

- **只能截屏幕上看得见的东西**。切到后台的窗口截不到。
- 滚动依赖模拟鼠标滚轮，所以**目标窗口得能正常响应滚轮**。有些自绘界面的应用可能滚不动。
- 自动连拍判断「到底了」是靠比较前后两屏画面，如果内容恰好高度重复（比如全是相同的表格行），可能提前停。
- 只在 Windows 上工作（用了 Win32 API 和 DPI 感知）。
- 面板是无边框自绘窗口，拖顶部深色条可以移动它。

## 实现要点

如果好奇里面怎么做的：

| 问题 | 做法 |
| --- | --- |
| 高 DPI 下坐标错位 | 启动前 `SetProcessDpiAwareness(2)`，全程用物理像素 |
| 红框挡住下面窗口的鼠标 | 红框窗口加 `WS_EX_TRANSPARENT`，做到真正的点击穿透 |
| 点按钮时抢走微信焦点 | 面板加 `WS_EX_NOACTIVATE`，永远不激活 |
| 面板收不到键盘事件 | 用 `GetAsyncKeyState` 全局轮询 End 键 |
| 截图时把自己拍进去 | 红框和面板临时调成 alpha=0，而不是隐藏（隐藏会导致窗口闪烁） |
| tkinter 做不出圆角 | 用 Canvas 自绘多边形按钮 |
